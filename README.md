# bruno-personal

Personal site — Bruno Salles.

Static, no build step. Open `index.html` or serve the folder:

```
python3 -m http.server 8000
```

## Files

- `index.html` — the site
- `support.js` — runtime the page loads
- `art/` — orb, footer bands, portrait

## Deploy

Works as-is on GitHub Pages: push to `main`, then Settings → Pages → deploy from branch `main`, root.
